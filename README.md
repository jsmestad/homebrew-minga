# Homebrew Tap for Minga

[Minga](https://github.com/jsmestad/minga) is a BEAM-powered modal text editor with a Zig terminal renderer and a native macOS GUI.

## Install the TUI binary

```bash
brew tap jsmestad/minga
brew install minga
```

## Install the macOS app

```bash
brew tap jsmestad/minga
brew install --cask minga-mac
```

## Updating

Formulas and casks are automatically updated when a new release is published. Just run:

```bash
brew update && brew upgrade minga
```
